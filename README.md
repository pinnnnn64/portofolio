# Alvin Ahmad Kurniawan — Portfolio

Mobile layout update for the personal portfolio website.

## Files
- `index.html` — portfolio website (HTML, CSS, and JavaScript included).
- `certificates/` — original PDF certificates opened by the credential cards.

## Run locally
Open `index.html` in a modern browser. Keep the `certificates` folder next to `index.html` so the original PDF links continue to work.

## Publish with GitHub Pages
Copy the contents of this package into the root of the `portofolio` GitHub repository, commit and push to `main`, then set **Settings → Pages → Deploy from a branch → `main` → `/(root)`**. The project website URL should be `https://pinnnnn64.github.io/portofolio/`.

## Mobile updates
- Navigation order is Home, About, Experience, Projects, Certificates, Writing, Contact.
- Hero portrait overlays the hero panel beside the text instead of dropping below it on small screens.
- About facts stack below the biography on mobile and tablet layouts.
- The detailed education cards now appear inside the About section; there is no standalone Education section.
- The theme toggle remains available as a compact floating control on small screens.
